# Contribuindo com a documentação viva

Documentação é parte do Definition of Done (critério de pronto).

1. Toda alteração funcional atualiza `04-funcionalidades.md` e `05-fluxos.md`.
2. Alterações em banco/API/integrador atualizam `02-arquitetura.md` e `03-dados-integracoes.md`.
3. Mudanças de papel, RLS, liberação de módulo e segurança atualizam `06-regras-permissoes.md`.
4. Migrações, comandos, smoke tests e rollbacks são registrados em `07-operacao-testes.md`.
5. Pendências avançam somente com evidência; cada entrega entra em `CHANGELOG.md`.
6. Manter `README.md` e índice navegáveis; links relativos funcionais.
7. Revisar anonimização, privacidade e segredos antes do commit.

Preferir Markdown no GitHub; PDF apenas quando solicitado. Planejamento pedagógico e regras comerciais devem ser identificados como propostas até homologados.
